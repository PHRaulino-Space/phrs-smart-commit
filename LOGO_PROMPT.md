# Logo Generation Prompt for 'phrs-smart-commit'

Use the following prompt in a tool like Gemini (Image Generation) to create a logo for this VS Code extension:

---

**Prompt:**

"Create a professional, minimalist, and modern logo icon for a VS Code extension named 'Smart Commit'. 

The extension automates the generation of Git commit messages using AI. The logo should visually bridge the concepts of version control and intelligent automation. 

**Key Design Elements:**
- **Core Concepts:** Incorporate elements like a Git branch node, a terminal icon, or code brackets combined with a subtle representation of AI (e.g., a spark, a glowing node, or a stylized neural synapse).
- **Style:** Clean, flat design, vector-style illustration. It must be highly legible and recognizable when scaled down to a small icon size (for the VS Code sidebar).
- **Color Palette:** Professional tech colors—deep blues, vibrant cyans, or modern purples. Suggesting a gradient from blue to purple could work well.
- **Constraints:** Avoid any text, letters, or complex photorealistic details. The background should be simple or transparent to allow for easy integration.

The final result should feel sleek, efficient, and developer-focused."
